# Glamour African Hair Braiding — Perry, GA

Fast, mobile-first local SEO website for Glamour African Hair Braiding.

## Included
- Single-page responsive website
- LocalBusiness / BeautySalon JSON-LD structured data
- Perry, GA-focused title and meta description
- Service sections for key braiding keywords
- Click-to-call and booking CTAs
- robots.txt and sitemap.xml
- No build step required

## Preview locally
Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080.

## Before production launch
1. Replace gallery placeholders with original salon/client photos for which the business has permission.
2. Confirm service prices and booking URL.
3. Confirm business hours before adding `openingHoursSpecification` to schema.
4. If the production domain changes, replace `https://glamourhair2024.com/` in `index.html`, `robots.txt`, and `sitemap.xml`.
5. Submit the sitemap in Google Search Console after deployment.
